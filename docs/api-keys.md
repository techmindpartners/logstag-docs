# API Keys

API keys authenticate Logstag agents to the Logstag backend.

This page will cover:

- Where API keys are created.
- How API keys are scoped to organizations.
- How agents use API keys.
- Rotation and revocation.
- Local configuration encryption.
- Operational checks after key changes.

API keys should be treated as sensitive credentials. Store them securely and rotate them when access changes.
