# Managed Targets

Managed targets are database targets that require cloud provider metadata in addition to database connection settings.

This page will cover:

- `self-hosted` targets.
- `aws-rds` targets.
- `huawei-rds` targets.
- Required cloud fields.
- Cloud credential handling.
- Verification steps.

Managed target documentation should explain both the database permissions and the cloud API permissions required for collection.
