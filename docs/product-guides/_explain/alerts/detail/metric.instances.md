How many distinct instances appear among the loaded occurrences for this template.

### How it's calculated

- Client-side unique count of `instanceName` over the same ≤100 header rows as Databases.
- Timeline bubbles use the same loaded set for the Y-axis (one series per instance).

### Reading it

If Occurrences is much larger than 100, treat this as a lower bound until you page through All Occurrences.
