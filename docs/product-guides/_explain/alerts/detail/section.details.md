Metadata for the selected alert occurrence in the split detail panel.

### How it's calculated

- Fields come from the selected `AlertItem` row (engine, category, check frequency, threshold, instance/database, scope, status, created, assignee, SLA, escalation/ticket) — not a separate detail endpoint for this table.
- Shown when the All Occurrences list is in split view. Description, impact, causes, and actions live in sibling panel sections; this help entry covers the Details table only.

### Reading it

Use Details to confirm where the signal fired and who owns it. If the row is muted, the panel banner links to Settings — muted alerts stay out of default list KPIs until you show muted.
