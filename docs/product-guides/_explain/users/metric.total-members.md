How many members belong to the organization, regardless of status or role.

### How it's calculated

- Counts every row returned by the unfiltered organization member list — not the Members table below, which can be narrowed by its own filters.
- Includes both Active members and members still in Invited status.

### Reading it

This number won't move when the Members table is filtered or searched. If it looks wrong, check whether you're comparing it against a filtered table view rather than the organization as a whole.
