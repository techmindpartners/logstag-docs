# Data Inventory: Metric Reference

This page is the source of truth for the in-app **Explain this** panels on the
[Data Inventory](https://app.logstag.com/data-inventory) page (`/data-inventory`). Each section is
written once as a content partial under `_explain/data-inventory/` and rendered both here and
inside the app's info panel (`scripts/build-explain.mjs` compiles the registry).

All KPIs and the table respect the topbar instance filter and only cover PostgreSQL and SQL Server,
the two classified engines. The single-table view is documented separately in the
[Detail reference](./detail.mdx).
