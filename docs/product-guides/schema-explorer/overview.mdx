# Overview Tab: Reference

This page is the source of truth for the in-app **Explain this** panels on the
[Schema Explorer](/product-guides/schema-explorer/) detail view's Overview tab.
Each section is written once as a content partial under `_explain/` and rendered both here
and inside the dashboard's info panel (`scripts/build-explain.mjs` compiles the registry).

## Object Counts and Schema Identity

The tab opens with count tiles for the object types the engine reports in this schema —
tables, indexes, views, procedures, functions, triggers, and sequences on relational engines;
collections, indexes, and documents on MongoDB. Oracle adds its Valid / Invalid / N/A object
validity split. Tiles appear only when the engine provides that object type.

An identity card lists the engine, hosting instance, database, and schema, and the schema
switcher in the page header jumps between schemas of the same database without losing tab
or time-window state.
