# User Management: Metric Reference

This page is the source of truth for the in-app **Explain this** panels on the
[User Management](https://app.logstag.com/users) page (`/users`). Each section is written once as
a content partial under `_explain/users/` and rendered both here and inside the app's info panel
(`scripts/build-explain.mjs` compiles the registry).

User Management requires the **ManageMembers** permission, held by Admin and SuperAdmin by default.
